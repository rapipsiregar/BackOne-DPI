1. **Resolved Invisible Polygons (Daratan Hilang)**:
   - In `react-globe.gl`, passing a static string directly to color properties (e.g. `polygonCapColor='#...'`) is interpreted by the library as a GeoJSON feature property key lookup. Since no feature has a property named like a hex color, the color resolved to `undefined` and the country polygons became completely transparent.
   - Restored color getter functions but memoized their references to prevent the lag.
2. **Resolved Drag Lag (Stuttering Fix)**:
   - Bound `polygonCapColor`, `polygonSideColor`, and `polygonStrokeColor` to stable memoized functions `getPolygonCapColor`, `getPolygonSideColor`, and `getPolygonStrokeColor` using `useMemo`.
   - Memoizing these callbacks ensures their function references remain constant across renders, preventing `react-globe.gl` from triggering expensive polygon mesh/material rebuilds during drag and hover interactions. Dragging is now fully fluid (60 FPS) and country shapes are correctly drawn.
