1. Latar Belakang & Tujuan Proyek

BackOne Deep Package Inspection (DPI) Dashboard adalah platform pemantauan keamanan dan analisis lalu lintas jaringan tingkat lanjut. Platform ini dirancang untuk mendeteksi ancaman, memetakan distribusi perangkat, dan memberikan wawasan realtime mengenai penggunaan bandwidth jaringan organisasi secara multi-tenant.

2. Arsitektur Sistem (Three-Tier Architecture)

Aplikasi ini dibangun menggunakan arsitektur tiga lapis yang andal dan aman:

  • Proxy Server (Collector): Berfungsi mengumpulkan telemetri jaringan mentah secara berkala (setiap 5 menit), melakukan deduplikasi data, menerapkan aturan retensi, dan menyimpannya langsung ke database.
  • MongoDB Database: Bertindak sebagai Single Source of Truth (satu-satunya sumber data valid) untuk memastikan konsistensi informasi yang disajikan di seluruh halaman.
  • Backend Server (Express) & Frontend (Next.js Standalone): Menyajikan REST API berkecepatan tinggi dengan isolasi ketat antar-penyewa (multi-tenant) dan hak akses pengguna (RBAC).

3. Fitur Utama Dashboard

Fitur Utama Deskripsi & Nilai Bisnis
Multi-Tenancy & RBAC Isolasi data yang aman antar-site (seperti SIAB dan Nexus) serta pembatasan fitur berdasarkan peran pengguna (Admin, SOC Analyst, Engineer).
Peta Interaktif Geografis Visualisasi sebaran letak fisik sensor jaringan (agents) di seluruh wilayah Indonesia beserta metrik performa masing-masing secara realtime.
Threat Intelligence & Audit Deteksi ancaman keamanan (seperti cryptomining, port scanning) dan pembuatan aturan pencegahan (*Blacklist Policy*) secara terisolasi per agent.
Kapasitas DB Realtime Perhitungan otomatis ukuran data (*Data Size*) per agent di database dengan efisiensi tinggi tanpa membebani kinerja server.
Analisis lalu lintas jaringan Visualisasi performa enkripsi TLS, pembagian kategori lalu lintas aplikasi (seperti streaming, hosting), dan detail perangkat aktif.

Catatan Keamanan Produksi:

Seluruh data kredensial, kunci JWT, dan konfigurasi API disimpan dengan aman di sisi server (Server-Side). Browser pengguna tidak memiliki akses langsung ke kredensial tersebut, sehingga sistem aman dari serangan melalui inspeksi browser (*inspect element*).

4. Status Deployment & Kebijakan Data Saat Ini

  • Domain Produksi: Aplikasi telah live 100% pada domain https://demoplace.my.id menggunakan Node.js v20 di bawah pengelolaan PM2.
  • Kebijakan Retensi Data: MongoDB hanya menyimpan data maksimal hingga 7 hari ke belakang secara otomatis (rolling 7 days) untuk menjaga kestabilan ruang penyimpanan server.
  • Zona Waktu Indonesia: Seluruh format penanggalan dan jam telah disesuaikan dengan zona waktu lokal Indonesia (WIB).
